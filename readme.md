# Zig Minesweeper

A minesweeper implementation in Zig 0.17, with a graphical and a command-line interface.

The code is 99.9% LLM-free, because I used this project to learn Zig and you obviously learn more when _doing_ the thing yourself. You can probably one-shot a much more complete version of what I wrote, but where's the fun in that!

### Running

Make sure your system has the necessary dependencies to use raylib (see [here](https://github.com/raysan5/raylib#build-and-installation) for details). Other than that, just run:

```
# Run in command-line mode
zig build run

# Run in graphical mode
zig build run -- pretty
```
